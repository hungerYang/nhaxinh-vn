## 项目分析：NhàXinh.vn (Next.js 16 + next-intl)

完成了对用户 AI 生成的装修设计分享网站的全面代码审查。

**项目概况：**
- Next.js 16 App Router，静态导出部署 GitHub Pages
- 三语言 (vi/zh/en)，next-intl v4.13.0
- Tailwind CSS v4，CSS Columns 瀑布流布局
- Fuse.js 客户端搜索，localStorage 持久化点赞/收藏

**发现的 5 个截图问题（均确认根因）：**
1. 产品图片：路径 .jpg 与实际 .webp 不匹配，12 产品仅 8 张独立图
2. HTML lang：代码层面正确，需浏览器复现确认
3. 双重 Footer：AffiliateProducts + Footer 视觉形成双底部
4. 点赞数：articles 无 likes 字段，用哈希伪随机数 1~50 冒充
5. 中文页越南语：submissions 未本地化，仅一份 submissions.json

**附加发现：**
- P0: ContentCards 点赞/收藏按钮无实际功能
- P0: 文章页重复 JSON-LD
- P1: basePath 硬编码、JWT localStorage XSS 风险、AuthProvider 静默吞错
- P2: 拼写错误 ngườii、搜索全部指向 shopee.vn 首页、Newsletter 装饰性

## 项目计划书审计
- 读取了 NhaXinh_项目计划书.docx（含8个表格），完成三维度分析：
  1. 计划与页面匹配度：核心功能70%覆盖，TikTok/Zalo/AdSense/1688等缺失
  2. 变现路径：5条建议（Shopee联盟→AdSense→设计合作→1688→内容赞助）
  3. 多语言投稿方案：字体、RTL、编码、特殊排版的完整技术方案
- 发现图片本地不显示的根因：next.config.mjs 缺少 basePath: '/nhaxinh-vn'，
  导致所有 /nhaxinh-vn/images/... 路径在本地 dev 中 404
- 已修复：next.config.mjs 加 basePath，layout.tsx preload .jpg→.webp，
  seo.ts og:image .jpg→.webp，page.tsx redirect 适配 basePath
- 三语路由验证全部 200，四类图片路径 (hero/products/rooms/articles) 全部可达
