## 一、引流策略（Traffic Acquisition）

### 1. SEO 自然流量

#### 1.1 已有基础

| 技术项目 | 状态 | 说明 |
|---------|------|------|
| JSON-LD 结构化数据 | ✅ 已完成 | 支持产品、文章、FAQ 等类型 |
| Sitemap | ✅ 已完成 | 自动生成，覆盖全站页面 |
| robots.txt | ✅ 已完成 | 配置合理的爬虫规则 |
| 多语言 SEO | ✅ 已完成 | 支持越南语、中文、英语 |

#### 1.2 待做：长尾关键词布局

针对越南语搜索习惯，系统布局长尾关键词矩阵：

| 关键词类别 | 示例关键词（越南语） | 搜索意图 | 优先级 |
|-----------|---------------------|---------|--------|
| 空间装修 | "thiết kế phòng khách chung cư nhỏ"（小户型客厅装修） | 信息型 | 高 |
| 空间改造 | "cải tạo ban công"（阳台改造方案） | 信息型 | 高 |
| 风格参考 | "phòng ngủ phong cách minimal"（极简风卧室） | 灵感型 | 高 |
| 预算相关 | "chi phí sửa nhà 30m2"（30平米装修费用） | 交易型 | 中 |
| 材料选购 | "gỗ tự nhiên hay gỗ công nghiệp"（实木还是人造板） | 对比型 | 中 |
| 局部改造 | "làm lại nhà tắm nhỏ"（小卫生间翻新） | 信息型 | 中 |

**执行要点：**

- 每个关键词创建独立的着陆页（Landing Page）
- 文章标题、H1、Meta Description 精准包含目标关键词
- 内链策略：相关文章互相引用，形成主题集群（Topic Cluster）
- 每月更新关键词库，根据 Google Search Console 数据调整

#### 1.3 内容营销（SEO驱动）

- **发布频率**：每周 2-3 篇高质量文章
- **内容方向**：
  - 装修知识科普（如"越南常见装修材料对比"）
  - 材料选择指南（如"如何选择适合越南气候的地板材料"）
  - 预算规划工具（如"胡志明市装修预算计算器"）
  - 案例分析（如"50m2公寓改造全记录"）

#### 1.4 技术 SEO 优化

| 优化项 | 目标 | 具体措施 |
|-------|------|---------|
| 页面速度 | LCP < 2.5s | 图片懒加载、代码分割、CDN加速 |
| 移动端适配 | Mobile-Friendly 100分 | 响应式设计、触控优化 |
| Core Web Vitals | 全绿通过 | 优化 CLS、FID、INP |
| 索引效率 | 48小时内收录 | 自动提交 Sitemap、Ping API |

### 2. 社交媒体引流

#### 2.1 Facebook（越南最大社交平台）

越南 Facebook 用户超过 7000 万，是家居装修领域最重要的流量来源。

| 运营动作 | 频率 | 内容形式 | 目标 |
|---------|------|---------|------|
| 创建 NhàXinh.vn Facebook Page | 一次性 | — | 品牌主页 |
| 发布装修灵感图片/视频 | 每日 1-2 条 | 图片/短视频 | 品牌曝光 |
| 加入装修相关群组 | 持续 | 文字+图片 | 社群运营 |
| Facebook Reels 短视频 | 每周 3-5 条 | 15-60秒视频 | 病毒传播 |

**重点群组（建议加入）：**

- "Cộng đồng decor"（装饰社区）
- "Thiết kế nội thất Việt Nam"（越南室内设计）
- "Nội thất đẹp"（美丽家具）
- "Xây dựng & Sửa chữa nhà"（建筑与房屋维修）

**Reels 内容方向：**
- 装修前后对比（Before/After）—— 转化率最高
- 装修小技巧（"1分钟学会选墙漆颜色"）
- 材料避坑指南
- 预算分享

#### 2.2 TikTok（越南年轻用户最多）

越南 TikTok 用户超过 5000 万，18-34岁用户占比极高，是触达年轻装修群体的关键渠道。

## 二、变现策略（Monetization）

### 第一阶段（0-3个月）：联盟营销

联盟营销是启动成本最低的变现方式，无需自有库存，通过导购赚取佣金。

#### 2.1.1 Shopee Affiliate

| 项目 | 详情 |
|------|------|
| 佣金比例 | 1%-10%（按品类不同） |
| Cookie 时效 | 3天 |
| 注册条件 | 拥有 Facebook / TikTok / YouTube 任一渠道 |
| 结算周期 | 月结 |

**操作步骤：**
1. 通过 Shopee Affiliate Platform 注册账号
2. 将现有网站商品区块的链接替换为 Affiliate 链接
3. 在社交媒体内容中嵌入 Affiliate 链接
4. 每周分析转化数据，优化高佣金品类

**预估收入**：初期 100-500 万 VND/月

#### 2.1.2 Lazada Affiliate

| 项目 | 详情 |
|------|------|
| 佣金比例 | 1%-10% |
| Cookie 时效 | 7天（比 Shopee 更长） |
| 注册渠道 | AccessTrade 或 Involve Asia |
| 核心优势 | Cookie 窗口更长，高客单价转化好 |

#### 2.1.3 TikTok Shop Affiliate

| 项目 | 详情 |
|------|------|
| 佣金比例 | 8%-20% |
| 核心优势 | 短视频带货，爆发力强 |
| 适用内容 | 装修好物推荐、家居产品测评 |

#### 2.1.4 AccessTrade（越南最大 Affiliate 平台）

| 项目 | 详情 |
|------|------|
| 平台定位 | 聚合多个电商平台的 Affiliate 项目 |
| 覆盖平台 | Shopee、Lazada、Tiki 等 |
| 核心优势 | 一个平台管理所有联盟项目，统一结算 |

**推荐接入顺序：**
1. AccessTrade（一站式接入多个平台）
2. Shopee Affiliate（流量最大）
3. TikTok Shop Affiliate（佣金最高）
4. Lazada Affiliate（Cookie 最长）

### 第二阶段（3-6个月）：广告收入

#### 2.2.1 Google AdSense

| 项目 | 详情 |
|------|------|
| 申请条件 | 网站上线 6 个月以上，有足够原创内容 |
| 越南市场 CPM | $0.5-$2（相对较低） |
| 预估月收入 | $50-$200（取决于流量规模） |

**优化建议：**
- 广告位放置在文章内容中间（In-feed Ads）
- 避免影响用户体验的弹窗广告
- 定期 A/B 测试广告位置和样式

#### 2.2.2 直接广告位销售

| 广告位 | 定价范围（VND） | 目标客户 |
|-------|----------------|---------|
| 首页 Banner | 500-2000万/月 | 家具品牌、建材商 |
| 文章内嵌广告 | 200-500万/篇 | 装修公司、家居品牌 |
| 侧边栏推荐位 | 300-800万/月 | 建材商、家电品牌 |

**目标客户画像：**
- 家具品牌（本地及进口品牌）
- 建材供应商（瓷砖、地板、涂料等）
- 装修公司（寻找客户线索）
- 家电品牌（厨房电器、智能家居等）


| 收费模式 | 价格 | 说明 |

| 按成交抽成 | 10%-15% | 成功签约后按合同金额抽成 |
